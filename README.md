# SpecimenMatchingBiotics
Python code and queries to match specimen data in Biotics to herbarium records downloaded from SEINet or other Symbiota frameworks.

Note: Your specimen label data must be stored in the following format or modifications must be made to the search pattern in the code.  

LastName, FirstName. Year. Specimen (collection/accession/catalog #XXXXX) at Herbarium Name.  
Example:  
Jones, G. N. 1962. Specimen (collection #34692) at University of Colorado Herbarium.
